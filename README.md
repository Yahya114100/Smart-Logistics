# PharmaLogix - Smart Logistics Platform

PharmaLogix is a premium, intelligent pharmaceutical logistics dashboard designed for the medical industry. It features real-time predictive analytics, temperature monitoring, humidity tracking, and advanced shipment filtering.

## 🚀 Getting Started

Follow these steps to get the project running on your local machine.

### Prerequisites

- **Node.js**: Version 18.0 or higher
- **npm** or **yarn**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Yahya114100/Smart-Logistics.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd pharmalogix
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

### Running the Project

1. **Start the development server:**
   ```bash
   npm run dev
   ```

2. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application in action.

## ✨ Key Features

- **Predictive Analytics**: Real-time risk detection for temperature and humidity.
- **Global Tracking**: Advanced filtering and export capabilities for all active shipments.
- **Premium UI**: Medical-grade aesthetic with dark mode and glassmorphism.
- **RTL Support**: Full support for right-to-left languages.
- **Smart Filters**: Filter by drug name, risk level, status, temperature, and more.
- **CSV Export**: Instant data export for auditing and reporting.

## 🛠 Tech Stack

- **Framework**: Next.js 15
- **Styling**: Tailwind CSS
- **Components**: Shadcn/UI
- **Icons**: Lucide React
- **Notifications**: Sonner
- **Maps**: Custom SVG-based Interactive Warehouse Map
